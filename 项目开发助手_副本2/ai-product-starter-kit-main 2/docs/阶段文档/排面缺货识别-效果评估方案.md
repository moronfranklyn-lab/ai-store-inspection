# 排面缺货识别 · 效果评估方案

| 项目 | 内容 |
| --- | --- |
| 所属功能 | 排面缺货识别（`SHELF_OOS`） |
| 文档目的 | 用真实门店照片给本功能的识别效果定标准，替代"拍脑袋定准确率" |
| 负责人 | 本功能产品经理 |
| 使用时机 | 第一版识别能力可用后，正式扩大范围之前 |
| 产出 | 判定门槛校准结论 + 本功能的验收标准 + 是否扩大范围的决策依据 |

---

## 1. 为什么必须这样做

本功能是"建议 + 人工复核"模式，所以**没有单一指标能定义它好不好**：

- 只看准确率会忽略"AI 挑得少但都对"这种情况——那等于没帮专员省时间。
- 只看节省时间会掩盖误报——误报多了专员会弃用，短期省的时间会全部还回去。
- 业务方（门店经营中心）关心的是"专员敢不敢用这个结论"，这个只有真实样例能回答。

因此本方案要一次拿到三组数据：**准不准、省不省时间、专员愿不愿意用**。

---

## 2. 评估样本怎么取

| 维度 | 要求 | 为什么 |
| --- | --- | --- |
| 门店数量 | **10 家** | 少于 5 家只能看到个例，多于 15 家第一版评估成本过高 |
| 每家照片数 | **20～30 张** | 对齐一次真实巡店任务的照片量 |
| 门店形态 | 至少覆盖 2 类：社区店、商圈/步行街店 | 两类店的货架布局与客流密度差异大，误报来源不同 |
| 光线条件 | 至少覆盖 3 类：正常、偏暗、强反光/逆光 | 阴影与反光是最主要的误报来源 |
| 拍摄角度 | 包含正拍、斜拍、含顾客遮挡三类 | 遮挡是"不确定"标注的主要触发条件 |
| 时间跨度 | 不同类型日各取一些（工作日/周末、日间/夜间） | 夜间与周末的门店状态差异明显 |
| 巡店规则集 | 覆盖"把货补满"与"门店常规巡检"两类 | 两类规则集对"缺货"的关注度不同 |

**样本总量**：约 200～300 张照片，合计可覆盖 10 家门店的巡店任务。

**样本要求**

- 必须是**真实巡店任务里的照片**，不用摆拍、不用公开数据集（公开数据集里没有零食连锁的货架形态）。
- 照片需带门店编号、任务编号、拍摄时间，以便回溯。
- 涉及顾客面部与员工影像的照片，按公司既有合规要求处理后再用于评估，**评估过程中的照片不得外发**。

---

## 3. 谁来做标注

| 角色 | 职责 |
| --- | --- |
| **远程巡店专员（2～3 名）** | 逐条标注 AI 结论对错、补录 AI 漏掉的缺货、记录本人复核耗时 |
| **门店经营中心（业务方）** | 裁决有争议的标注（例如"这算不算正常排面调整"），确认最终判定口径 |
| **本功能产品经理（我）** | 组织评估、设计标注表、汇总数据、输出校准结论与验收标准、做扩大范围的建议 |
| **AI 巡店项目负责人** | 决策是否扩大范围、协调资源 |

**为什么要 2～3 名专员**：不同专员对"缺货"的判定尺度本身就有差异。如果只有一个人标，会把个人尺度当成标准；多人标注能顺带量化**人与人之间的判定分歧**——这个分歧就是 AI 判定口径要收敛的目标区间。

---

## 4. 标注表怎么填

每条 AI 建议结论，专员只需选一个结果，并记录两类信息。

**标注字段**

| 字段 | 取值 | 说明 |
| --- | --- | --- |
| 建议编号 | 系统自动 | 对应建议清单里的一条 |
| 专员判定 | **对 / 错 / 不确定项判断正确 / 不确定项本可判定** | 四选一，避免"基本对"这种模糊选项 |
| 错在哪（判错时） | **位置错 / 层数错 / 把正常排面报成缺货 / 其他** | 用于定位误报的具体来源 |
| 是否补录漏检 | 是 / 否 | 是则记录漏检的位置与层数 |
| 本条复核耗时 | 秒 | 可由系统自动计时，也可人工粗记 |

**每家门店还要记两条**

| 字段 | 说明 |
| --- | --- |
| 本项复核总耗时 | 从看到清单到完成本项，用于对比人工方式 |
| 人工方式对照耗时 | 同一家门店由专员按原方式（自己翻照片找缺货）走一遍的耗时，用于算出节省幅度 |
| 主观可用性打分 | 1～5 分：这家门店的识别结果，你敢不敢直接用 |

**人工方式对照必须做**：否则"节省 8 分钟"是无法验证的说法。对照不需要每家门店都做，**10 家里挑 3～4 家做对照即可**，但要覆盖不同门店形态。

---

## 5. 算出哪些指标

| 指标 | 算法 | 用来看什么 |
| --- | --- | --- |
| **建议准确率** | AI 建议中专员判"对"的条数 ÷ AI 建议总条数 | 专员会不会因为误报多而弃用 |
| **误报率** | 专员判"错"的条数 ÷ AI 建议总条数 | 误报的主要来源（位置/层数/正常排面） |
| **漏检率** | 专员补录条数 ÷（专员补录条数 + AI 建议中判"对"的条数） | AI 有没有整层、整张照片地漏 |
| **"不确定"标注的诚实度** | "不确定项判断正确" ÷（"不确定项判断正确" + "不确定项本可判定"） | 有没有该判却硬猜、或不该判却推给人 |
| **覆盖率** | 有 AI 建议的门店数 ÷ 评估门店数 | AI 是否在某些门店形态下完全失效 |
| **单店本项平均耗时** | 各门店本项复核耗时均值 | 是否真的省时间 |
| **耗时节省幅度** | （人工方式对照耗时 − 本项复核耗时）÷ 人工方式对照耗时 | 对齐集团"单次巡店省 8 分钟"的口径 |
| **专员可用性均分** | 各门店主观打分均值 | 最终"敢不敢用"的判断 |
| **专员间判定分歧率** | 不同专员对同一张照片判定不一致的比例 | 口径本身有多模糊，决定检查表要不要写更细 |
| **AI 结论重复一致性** | 同一批照片连跑两次，结论不一致的条数 ÷ 建议总条数 | 2025 年 VLM 的现实短板：同一张图多次推理可能给不同结论。结论不稳，专员就无法建立信任 |

**一致性测试必须单独做**：从 10 家门店里抽 2～3 家，把照片**原样连跑两次**（不改提示词、不改参数），对比两次建议清单的差异。这一步同时验证"后台多次采样取多数"这个产品对策是否真的起作用。

## 6. 结果怎么用（这是本方案的核心）

评估不是为了拿一个好看的分数，而是为了做四个具体决定：

**决定一：判定门槛定在哪**

用"把正常排面报成缺货"的误报条数反推。例如：
- 连续 2 个空位就报 → 误报集中在"正常排面调整" → 门槛应提高到连续 3 个及以上。
- 门槛提到 4 个后漏检明显上升 → 门槛回调到 3 个，或按门店形态分别设门槛。
- **结论形式**：写清"连续 N 个空位判定，误报率 X%、漏检率 Y%"，交给门店经营中心确认。

**决定二：哪些情况当前不可识别**

若某类情况（如强反光、货架下层被遮挡、极暗）误报或漏检显著高于平均，则：
- 第一版把这些情况**排除出识别范围**，或强制标"不确定"，并在产品上向专员说明。
- **不要硬做**——在这类情况上出错比不识别更伤信任。

**决定三：验收标准写什么数字**

用真实打分结果反推本功能的验收线。例如（数字为示例格式，实际以评估结果填入）：
- 建议准确率不低于 __%
- 漏检率不高于 __%
- "不确定"标注诚实度不低于 __%
- AI 结论重复一致性不低于 __%（同一批照片连跑两次的结论一致比例）
- 单店本项耗时节省不低于 __ 分钟

**这几个数字写进本功能的验收标准，而不是事先拍一个 95%。**

**决定四：要不要扩大范围**

建议的扩大条件（四条同时满足才建议扩大）：
1. 建议准确率与"不确定"诚实度都达到评估后确定的验收线；
2. AI 结论重复一致性达标（否则规模一放大会变成大量申诉与返工）；
3. 耗时节省幅度达到业务侧认可的水平；
4. 专员可用性均分达到"愿意继续用"的水平（例如均分 ≥ 4）。

**任一不满足**：先修口径与提示词，重跑评估，不扩大范围。

---

## 7. 评估的执行步骤

1. **准备样本**（产品经理）：按第 2 节取样，确认合规处理完成，整理成评估清单。
2. **对齐标注口径**（产品经理 + 门店经营中心）：先用 20 张照片做一次小范围试标，把分歧当场裁决掉，形成标注说明——**这一步不做，后面 200 张的标注会白做。**
3. **正式标注**（专员）：按第 4 节填表；每家的本项复核耗时由系统自动记录。
4. **人工对照**（专员）：3～4 家门店按原方式走一遍并计时。
5. **一致性测试**（产品经理）：抽 2～3 家门店的照片原样连跑两次，对比两次建议清单的差异。
6. **汇总与出结论**（产品经理）：算第 5 节指标，出第 6 节四项决定。
7. **评审**（产品经理 + 门店经营中心 + 项目负责人）：确认门槛与验收标准，决定是否扩大范围。

**时间预期**：样本准备与试标约 1 天，正式标注 2～3 天（专员兼职做），汇总与评审 1 天。

## 8. 容易做错的地方

| 坑 | 后果 | 怎么避免 |
| --- | --- | --- |
| 只让一个专员标 | 把个人尺度当成标准，换个人结果就变 | 至少 2 人，并计算分歧率 |
| 样本只在光好的门店取 | 准确率虚高，一铺开就崩 | 强制覆盖偏暗与反光 |
| 只算准确率不算耗时 | 无法回答"到底省了多少时间" | 必须有 3～4 家人工对照 |
| 没做试标就直接标 200 张 | 标注口径不一致，数据作废 | 先试标 20 张并裁决分歧 |
| 拿评估结果去宣传"准确率 X%" | 对外承诺无法持续兑现 | 评估结果只用于内部定门槛与验收线 |
| 用摆拍照片评估 | 结果与真实巡店照片完全脱节 | 只用真实巡店任务里的照片 |
| 忽略"补录漏检" | 只看到误报看不到漏检，以为效果很好 | 漏检必须单独记录并进指标 |
| 只跑一次就下结论 | 2025 年 VLM 结论不可复现，单次结果可能只是运气好 | 抽 2～3 家原样连跑两次，算结论一致性 |
| 拿海外闭源模型的效果当自己的预期 | 合规上不可用，预期会落空 | 只测国内可合规调用的候选模型 |
